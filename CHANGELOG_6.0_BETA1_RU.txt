ZEMY ANIME 6.0 BETA 1 — YUMMYANIME CATALOG INTEGRATION

Основа: исходники ZEMY ANIME 5.0 Beta 1. Сохранены прежний фиолетовый интерфейс, Shikimori RU, избранное, история, продолжение просмотра и Media3-плеер.

НОВОЕ
- Добавлен YummyAnimeProvider для официального YummyAnime API — каталога, который использует DAVY.
- Добавлены поиск и страницы каталога через GET /anime с X-Application, Lang: ru, limit, offset и q.
- Добавлены режимы каталога: популярное, онгоинг, топ, фильмы и анонсы.
- Добавлена загрузка деталей тайтла и метаданных опубликованных видео: номер серии, название озвучки и имя плеера.
- В карточке просмотра можно открыть список доступных вариантов перевода.
- Добавлено поле публичного токена приложения YummyAnime в настройках. Пароль аккаунта вводить не нужно.
- Shikimori остаётся запасным каталогом: удаление токена возвращает Shikimori.
- ID YummyAnime хранятся в отдельном отрицательном диапазоне, чтобы не конфликтовать с ID Shikimori в локальных избранном и истории.
- Каталог ограничивает выдачу рейтингами PG и PG-13; записи без рейтинга и более взрослые записи отфильтровываются.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Это интеграция каталога и метаданных YummyAnime API, используемого DAVY, а не встраивание или переименование самого приложения DAVY.
- Публичный X-Application токен обязателен. Его можно получить на https://yummyani.me/dev/applications. API заявлен владельцем для личного использования.
- API возвращает iframe_url для сторонних видеоплееров. ZEMY не извлекает из iframe прямые потоки и не обходит авторизацию, DRM или ограничения источников.
- Для воспроизведения через Media3 по-прежнему требуется прямая HTTPS-ссылка на видео/поток, которую разрешено встраивать. Метаданные переводов не означают, что поток доступен для Media3.
- Код DAVY и парсер DAVY не копировались; AGPL-код не включён в этот проект.
