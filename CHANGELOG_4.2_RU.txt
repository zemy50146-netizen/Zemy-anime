ZEMY ANIME 4.2 — MULTI-SOURCE PLAYER

Что изменено в этой сборке:
- Убрана фиктивная подстановка 12 серий, если каталог не сообщает количество эпизодов.
- Список эпизодов строится по числу серий, переданному из каталога Shikimori.
- Для каждой серии можно сохранить несколько собственных разрешённых прямых видеоисточников.
- Добавлен выбор источника, добавление дополнительных источников и удаление сохранённых источников серии.
- Сохранённые ссылки из ZEMY 4.0 автоматически читаются как старый одиночный источник.
- В настройках плеера добавлено реальное ограничение максимального разрешения видео.
- Выбор аудиодорожки и субтитров открывает системный диалог Media3, если поток предоставляет соответствующие дорожки.
- Сохранён Media3 ExoPlayer 1.5.1 и Java 17; сторонние библиотеки с требованием Java 21 не добавлялись.

Ограничения:
- Это не означает, что приложение автоматически получает серии из Shikimori: Shikimori остаётся каталогом метаданных.
- Автоматическая интеграция AniLiberty API ещё не включена в эту сборку; её нужно делать отдельным API-адаптером по актуальной OpenAPI-схеме.
- Дорожки аудио/субтитров и варианты качества доступны только если они присутствуют в источнике.
- Принимаются прямые ссылки на совместимые видеофайлы/плейлисты, которые разрешено встраивать. Защита DRM и авторизация сторонних сервисов не обходятся.

Сборка APK в этой среде не выполнялась: в архиве отсутствует Gradle Wrapper и Android SDK. Импортируй корневую папку проекта в CodeAssist, выполни Gradle Sync и Build.
