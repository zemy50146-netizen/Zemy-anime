ZEMY ANIME 8.1 — SERVER CONNECT (SERVER FOUNDATION)

В этой версии добавлена отдельная серверная основа ZEMY Server 0.1.

Что появилось:
- REST API собственного каталога аниме.
- API карточки аниме и списка сезонов/серий.
- Административные API для добавления аниме и серий.
- Защищённая загрузка видео с Bearer-токеном.
- Отдельное хранение метаданных (SQLite) и файлов видео.
- Endpoint потока серии, который в дальнейшем подключается к Media3 ExoPlayer.
- Dockerfile, requirements.txt и инструкция на русском.

Чего пока нет:
- Android-приложение ещё не подключено к ZEMY Server.
- Нет готовой публичной панели администратора.
- Сервер ещё не размещён в интернете и не имеет постоянного домена.
- HLS-пакеты с сегментами и CDN требуют отдельной реализации.
- APK не собирался в этой среде.

Важно: сервер предназначен для собственного или лицензированного видеоконтента. Он не скачивает и не извлекает серии со сторонних площадок.

План версий не меняется: бета завершается на 9.0, затем первый стабильный релиз — 1.0.
