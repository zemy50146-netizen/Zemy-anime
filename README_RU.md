# ZEMY ANIME 6.0 Beta 1 — YummyAnime Catalog Edition

В этой версии к Shikimori RU добавлен дополнительный каталог через официальный YummyAnime API — тот же каталоговый backend, который использует DAVY. Это не копия приложения DAVY и не встраивание его исходников.

## Подключение YummyAnime
1. Открой ZEMY → меню → Настройки → «Подключить YummyAnime (каталог DAVY)».
2. Нажми «Получить токен» или открой https://yummyani.me/dev/applications.
3. Создай собственное приложение на стороне YummyAnime и скопируй его публичный `X-Application` token.
4. Вставь только публичный токен приложения в ZEMY. Не вводи пароль от аккаунта.
5. Каталог переключится на YummyAnime. Чтобы вернуться к Shikimori, выбери «Использовать Shikimori RU».

YummyAnime API заявлен владельцем как API для личного использования. В этой интеграции используются поиск, каталог, карточки тайтлов и метаданные доступных серий/переводов. Для каталога установлено ограничение PG/PG-13; записи без возрастного рейтинга и более взрослые записи не показываются.

## Что важно по просмотру
API может вернуть `iframe_url` стороннего плеера. ZEMY не извлекает из iframe прямые потоки и не обходит ограничения сторонних источников. Встроенный Media3 Player продолжает воспроизводить прямые HTTPS-ссылки на видео/потоки, которые разрешено встраивать. Список переводов в карточке — это метаданные наличия, а не гарантия, что соответствующий поток доступен для Media3.

## Сборка
Версия приложения: `6.0-beta1`, `versionCode 22`. Java 17, minSdk 23, Media3 1.5.1 (ExoPlayer, HLS, DASH). Сохранены улучшения 5.1: MP4/M3U8/MPD, выбор аудиодорожек, внешние VTT/SRT-субтитры, несколько источников на серию, продолжение просмотра и ограничение качества. APK в этой среде не собирался; импортируй корневую папку проекта в CodeAssist, дождись Gradle Sync и выполни Build APK.

# ZEMY ANIME 2.8 — RU ONLY

Android-каталог аниме с фиолетовым интерфейсом. Поиск и каталог используют только русскоязычный источник Shikimori.

## Импорт
1. Распакуйте ZIP.
2. Импортируйте корневую папку `ZEMY_ANIME_2.0` как Gradle-проект.
3. Дождитесь Gradle Sync и соберите APK.

## Русский каталог
- Единственный внешний каталог поиска: Shikimori (`shikimori.one`).
- AniList, Jikan/MyAnimeList, Kitsu и Internet Archive не используются для поиска в этой версии.
- В выдачу попадают только записи, у которых заполнено русское название. Если русского описания нет, показывается сообщение об этом, а не английский текст.
- Жанры берутся из русских названий, когда они доступны.
- Постеры загружаются с домена Shikimori.

## Просмотр
Shikimori — каталог метаданных, а не видеохостинг. Для просмотра можно открыть российские онлайн-кинотеатры: Кинопоиск, Wink, Okko и Иви. Наличие конкретного тайтла и русского перевода зависит от региона и лицензии. Также можно добавить собственную разрешённую прямую ссылку на совместимый видеофайл/поток. Приложение не обходит DRM, платный доступ или авторизацию.

## Ограничения
Связанные сезоны пока показывают текущую часть: автоматическая загрузка связей из англоязычного каталога отключена. Некоторые фильтры каталога могут быть приблизительными, поскольку используются параметры Shikimori.

## Сборка
Android Gradle Plugin 8.7.3, Kotlin 2.0.21, compileSdk 35, minSdk 23, Java 17. APK в этой среде не собирался; проверьте Gradle Sync и Build в вашей версии CodeAssist.

## Если CodeAssist показывает `Unresolved reference: media3`

Это обычно означает, что Gradle не загрузил зависимости Media3 или проект открыт не из корневой папки.
1. Импортируйте весь архив и откройте папку `ZEMY_ANIME_2.0` (в ней находятся `settings.gradle.kts` и корневой `build.gradle.kts`), а не только `app`.
2. Включите интернет и выполните Sync/Reload Gradle Project. Не включайте Offline mode.
3. Проверьте, что в `app/build.gradle.kts` есть зависимости `androidx.media3` версии `1.5.1`.
4. После успешной синхронизации запустите Clean Project, затем Build APK.

Если ошибка остаётся, пришлите первые строки Gradle Sync/Build Output: важно увидеть, не блокируется ли загрузка артефактов из Google Maven.


## ZEMY 8.2 — автоматическое подключение сервера

Вкладки сервера в приложении нет. При открытии карточки ZEMY автоматически ищет точное совпадение названия через `/api/v1/match`, загружает сезоны/серии и запускает доступную серию во встроенном Media3-плеере. Перед использованием разместите сервер на HTTPS и замените `YOUR-ZEMY-SERVER.invalid` в `ZemyServerClient.kt` на реальный домен.
