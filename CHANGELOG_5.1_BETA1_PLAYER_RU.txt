ZEMY ANIME 5.1 BETA 1 — ВСТРОЕННЫЙ ПРОСМОТР

Что улучшено в просмотре:
- Встроенный Media3-плеер принимает прямые HTTPS-ссылки на MP4, HLS/M3U8, DASH/MPD, M4V и WebM.
- Добавлена зависимость Media3 DASH для воспроизведения MPD.
- Для каждого источника можно сохранить отдельный внешний файл субтитров VTT или SRT.
- Субтитры прикрепляются к MediaItem и доступны в меню дорожек плеера.
- Сохраняется выбор нескольких источников для каждой серии; выбор источника показывает, подключены ли внешние субтитры.
- Сохранена функция продолжения просмотра и восстановление позиции.
- Удалён дублирующий val options в меню серии, который мешал компиляции Kotlin.
- Кнопка перехода к сервисам переименована в «Официальные сервисы».

Ограничения:
- Это встроенный плеер для прямых потоков, которые владелец/провайдер разрешает встраивать.
- Автоматический поиск релизов и извлечение потоков со сторонних iframe-сайтов не добавлены. Shikimori предоставляет метаданные, но не видеопотоки.
- Приложение не обходит DRM, платную авторизацию или ограничения доступа.
- Для реального каталога релизов потребуется документированный API видеопровайдера, который разрешает стороннее воспроизведение.

Сборка: Java 17, minSdk 23, Media3 1.5.1. APK в этой среде не собирался; проверьте Gradle Sync и Build в CodeAssist.
