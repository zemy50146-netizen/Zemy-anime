ZEMY ANIME 4.3 BETA 1 — CONTINUE WATCHING

Что нового:
- Добавлена функция «Продолжить просмотр» на странице аниме.
- Плеер сохраняет последнюю серию и позицию воспроизведения локально на устройстве.
- При повторном запуске той же серии Media3 восстанавливает сохранённую позицию после подготовки потока.
- На странице просмотра появляется отдельная карточка продолжения с номером серии и временем остановки.
- Позиция обновляется при паузе, остановке плеера, перемотке и уходе приложения в фон.
- При достижении конца серии сохранённая позиция этой серии очищается.
- Данные прогресса хранятся отдельно для каждого anime ID и номера серии; сетевые аккаунты и облачная синхронизация не требуются.

Совместимость:
- Сохранены каталог Shikimori, ручные источники и миграция ссылок 4.0.
- Сохранены Media3 ExoPlayer 1.5.1, HLS, выбор доступных аудиодорожек/субтитров и ограничение качества.
- Java 17 и minSdk 23 не менялись.

Ограничения бета-версии:
- Продолжение просмотра работает для прямых совместимых потоков, добавленных пользователем и разрешённых к встраиванию.
- Позиция хранится локально; после очистки данных приложения она пропадёт.
- Список серий не генерируется искусственно: используется количество серий из каталога или вручную добавленные серии.
- AniLiberty API не подключён в этой бета-сборке; его интеграцию нужно выполнять отдельно по актуальной OpenAPI-схеме.

Проверка:
- ZIP проверяется на целостность.
- APK в этой среде не собирался: для проверки Gradle Sync/Build импортируйте корневую папку проекта в CodeAssist.
