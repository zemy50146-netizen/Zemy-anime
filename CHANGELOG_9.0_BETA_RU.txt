ZEMY ANIME 9.0 BETA — ОБЪЕДИНЁННАЯ СБОРКА

ANDROID
- Сохранён существующий интерфейс, каталог и встроенный Media3-плеер.
- Адрес ZEMY Server вынесен в Gradle-параметр ZEMY_BASE_URL; нет фиктивного URL в Kotlin.
- Серверный адрес задаётся только после публикации Cloudflare Worker.

CLOUDFLARE SERVER
- Worker API и D1 SQL migration включены в server/cloudflare.
- AniList scanner: до 50 не-взрослых тайтлов за запуск, расписание каждые 6 часов, последовательный обход страниц.
- Настройки языка метаданных: ru/en/ja/uk; отсутствие перевода не маскируется выдуманным текстом.
- Административные endpoints защищены Bearer-токеном.
- Каталог хранится в D1; опциональный R2 используется только для временного кэша.
- GitHub Actions workflow публикует Worker после настройки секретов владельцем.

ZEMY MUSIC ID
- Подготовлены таблица и API точного поиска заранее зарегистрированного fingerprint.
- Захват звука и генерация отпечатка не реализованы; это не готовое распознавание музыки.

ОГРАНИЧЕНИЯ
- AniList предоставляет метаданные, не видео и не озвучки.
- Для Media3 нужны разрешённые прямые HTTPS-потоки; iframe и страницы плееров не поддерживаются как прямые потоки.
- Сервер не обходит DRM, авторизацию или платные ограничения.
- Worker не является постоянно работающим VPS; Cron выполняет периодические задачи.
- Для публикации требуются действия владельца в GitHub и Cloudflare: создание D1, добавление секретов и push в main.
- APK не компилировался в этой среде.
