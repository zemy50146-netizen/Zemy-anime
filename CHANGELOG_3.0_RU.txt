ZEMY ANIME 3.0 — SHIKIMORI + ANILIBERTY

Что изменено:
- Добавлен отдельный адаптер публичного AniLiberty API v1.
- Поиск релизов выполняется по точному Shikimori ID, а не только по похожему названию.
- В плеере добавлена кнопка «Найти релизы AniLiberty».
- При наличии опубликованного эпизода приложение предлагает прямой HLS-поток, возвращённый API.
- Если прямой поток не предоставлен, приложение не пытается извлекать его со сторонних страниц.
- Существующий каталог Shikimori и фиолетовый интерфейс сохранены.

Ограничения:
- В этой первой интеграции отображается опубликованный эпизод, который API возвращает в карточке релиза; полный список серий и выбор озвучки ещё не реализованы.
- Android VideoView не даёт полноценного ручного выбора аудиодорожек/субтитров.
- Сборка APK в Android SDK/CodeAssist здесь не выполнялась. ZIP проверяется отдельно на целостность.
