ZEMY ANIME 7.0 BETA 1

ИЗМЕНЕНИЯ
- Удалены лишние кнопки «Официальные сервисы», «Тест плеера» и дублирующие «Виде источники» на странице просмотра.
- Полноэкранный режим перенесён внутрь панели управления Media3 — рядом с кнопкой паузы/воспроизведения.
- Сохранена кнопка добавления собственного разрешённого видеопотока и настройки аудио/субтитров.
- Версия приложения обновлена до 7.0-beta1 (versionCode 23).
- Сохранено подключение каталога YummyAnime через публичный X-Application токен.
- Для серий YummyAnime добавлен выбор доступной озвучки и открытие возвращённой API страницы плеера во внешнем браузере. Если ссылка отсутствует, приложение сообщает об этом и оставляет ручное добавление разрешённого источника.

ВАЖНО
YummyAnime API в этой сборке используется для каталожных данных, количества серий и метаданных переводов. Поле player в API является страницей/плеером стороннего сервиса, а не гарантированной прямой ссылкой на видео. Эта сборка не извлекает и не обходит защиту сторонних видеоплееров. Для встроенного Media3-плеера нужен прямой HTTPS-поток, который владелец источника разрешает встраивать.
